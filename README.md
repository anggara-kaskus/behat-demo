# behat-demo
This repository contains a simple library for calculator apps.

## Calculator App

This repository includes a simple calculator application written in Python. The calculator can perform the following operations:

- Addition
- Subtraction
- Multiplication
- Division

### Usage

```python
from calculator import Calculator

calc = Calculator()
print(calc.add(1, 2))        # Output: 3
print(calc.subtract(5, 3))   # Output: 2
print(calc.multiply(4, 3))   # Output: 12
print(calc.divide(10, 2))    # Output: 5.0
```
