# behat-demo

This project is a demonstration of using Behat for behavior-driven development (BDD). Behat is a PHP framework for automated testing of your application’s behavior. This demo includes sample features and scenarios to help you get started with BDD using Behat.

## Getting Started

### Prerequisites

- PHP 7.3 or higher
- Composer

### Installation

1. Clone the repository:

```sh
$ git clone https://github.com/anggara-kaskus/behat-demo.git
```

2. Navigate to the project directory:

```sh
$ cd behat-demo
```

3. Install the dependencies:

```sh
$ composer install
```

## Running Tests

To run the Behat tests, use the following command:

```sh
$ vendor/bin/behat
```

## Project Structure

- `features/`: Contains the feature files written in Gherkin language.
- `bootstrap/`: Contains the context classes.
